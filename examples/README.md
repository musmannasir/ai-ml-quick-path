# Examples

All data is synthetic and generated by the scripts. Requirements: Python 3.10+ with
`numpy`, `pandas` and `scikit-learn` (`pip install numpy pandas scikit-learn`).
Run everything with `npm run test:examples`.

| Folder | What it shows | Used by lessons in |
|---|---|---|
| `quickpath/quickpath.py <demo>` | Main demo file for this guide: env, rules_vs_ml, lifecycle, data, anomaly, pca, bpe, bigram, sampling, llm_size, lora, chunking, hybrid, pii, fairness, cache, serving, registry, batching (or `all`) | Every part |
| `ml-basics/ml_basics.py` | Features, quality checks, gradient descent, cross-validation, k-means, metrics, drift (PSI) | Parts 2, 3, 7 |
| `gap-topics/gap_topics.py` | SQL, data visualisation, regression, SVM, ROC, tuning and Shapley values, word vectors, time series, recommenders, vision, speech, graph networks, policy gradients | Parts 2–4 |
| `ai-extras/ai_extras.py` | Algorithms comparison, neural network, convolution, RNN, dropout, diffusion, Q-learning | Parts 3–4 |
| `applied-ai-basics/applied_basics.py` | Cosine similarity, evaluation scoring, latency percentiles | Parts 6–7 |
| `math/math_for_ai.py abtest` | A/B test significance (used by the evaluation lesson; a worked example is in the lesson's Applied Maths section) | Part 6 |
| `spam-classifier/` | TF-IDF + logistic regression spam classifier | Part 3 |
| `attention/` | Scaled dot-product attention in NumPy | Part 4 |
| `tiny-lm/` | Character-level language model trained on a laptop CPU in NumPy | Part 5 |
| `memory-estimate/` | GPU memory arithmetic for inference and fine-tuning | Part 5, hardware page |
| `rag-leave-policy/` | RAG over a short leave policy (offline retrieval; model call optional) | Part 6 |
| `agent-returns/` | Framework-free agent workflow with an approval step | Part 6 |
| `llm-summarizer/` | Structured-output summariser with schema validation and tests (offline mode) | Part 6 |
| `hybrid-service/` | FastAPI model service + ASP.NET Core typed client (not run: FastAPI and .NET not installed) | Part 7 |
| `lesson-code/` | Every Python and C# block from the lessons as files (see its README) | All |

Timings printed by `quickpath.py serving` and `batching` depend on your machine; every other number is
deterministic (fixed random seeds) and matches the lessons.
